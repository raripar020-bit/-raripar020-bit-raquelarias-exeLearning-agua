🔐 ¿Qué son las licencias?
Son cosas que sirven para darte o no permiso para poder descargarte
algo de la red o usarlo para un trabajo tuyo o en grupo (imágenes para un
blog, vídeos para una página web, música para un podcast...)
Existen distintos tipos de licencias, ¡fíjate bien! y mira sus símbolos:
COPYRIGHT: significa “Todos los derechos reservados”. Se simboliza con
una C dentro de un círculo ©. Necesitarias permiso del autor.
PUBLIC DOMAIN: cosas que puedes usar, descargar... sin problema.
COPILEFT: el autor puede dejarte que uses una parte de su trabajo, no
la totalidad. Se simboliza con una C al revés dentro de un círculo.
Otras menos conocidas: Creative Commons, Gnu/Gpl... ¡pregunta a un
adulto!
